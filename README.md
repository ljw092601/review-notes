# 오답노트 (ReviewNotes)

정보처리기사 실기 공부용 오답노트. 서버 없이 브라우저(IndexedDB)에만 저장한다.

## 매일 쓰는 법

```
npm run dev          # http://localhost:5173
```

빌드해서 쓰려면 `npm run build && npm run preview`.

### 바탕화면 아이콘으로 열기 (Windows)

바탕화면의 **ReviewNotes** 바로가기를 더블클릭하면 서버가 꺼져 있으면 켜고, 크롬으로 앱을 연다.
서버는 최소화된 창으로 돌아가고 그 창을 닫으면 꺼진다. 바로가기가 없으면 한 번만 만든다:

```
powershell -ExecutionPolicy Bypass -File scripts\make-shortcut.ps1
```

주소는 항상 `http://localhost:5173`이다. 브라우저 저장소(IndexedDB)는 주소별로 따로 있어서 포트를 바꾸면 데이터가 안 보인다.

### 사진으로 문제 넣기

1. 틀린 문제 사진을 `inbox/<오늘 날짜>/`에 넣는다. (예: `inbox/2026-10-09/IMG_001.jpg`)
2. Claude Code에서 **"오답 정리해줘"** 라고 한다. Claude가 사진을 읽어 문제·유형·정답을 채운 `inbox/<날짜>/<날짜>.json`을 만든다.
3. 앱의 **가져오기**에 그 파일을 드롭한다. 이미 있는 문제(같은 출처나 본문)는 기본으로 건너뛰고, **덮어쓰기**를 고르면 문제·정답·풀이·태그·사진을 파일 내용으로 바꾼다(틀린 이유·복습 기록은 유지). Claude가 풀이를 다시 써 줬을 때 쓴다.
4. **입력 필요** 화면에서 틀린 이유를 적고, Claude가 미리 채워 둔 풀이(핵심 개념을 표·목록으로 정리한 것)를 다듬는다.

### 복습

**복습** 메뉴에서 범위(전체 / 최근에 틀린 것 / 아직 안 풀어본 것 / 정리 끝난 것)를 고르고 시작한다. 문제만 보고 답을 쓴 뒤 정답·풀이를 보고 틀림/부분/맞음으로 채점한다.

### 자동 백업 (권장)

**가져오기 / 내보내기** 페이지의 "자동 백업" 카드에서 PC 폴더를 **한 번만** 고르면, 그 뒤로는 문제를 저장·수정·삭제하거나 복습할 때마다 그 폴더에 자동으로 저장된다. 앱은 계속 IndexedDB로 돌고, 폴더는 사람이 보는 사본이자 복구용이다.

폴더 구조:

```
<고른 폴더>/
  review-notes.json                      ← 항상 최신 상태. 매번 덮어쓴다
  images/<사진id>.png|jpg                ← 사진 원본. 지운 문제의 사진은 다음 백업 때 정리
  history/review-notes-YYYY-MM-DD.json   ← 날짜가 바뀔 때 직전 상태를 스냅샷으로 보관. 최근 30일치
```

- Chrome·Edge에서만 된다(File System Access API). 다른 브라우저에서는 아래 수동 내보내기를 쓴다.
- 브라우저를 새로 열었을 때 폴더 권한을 다시 물으면 화면 위 배너의 "허용"을 누른다. 허용 전까지는 백업이 멈춘다.
- 브라우저 데이터가 사라졌거나 다른 PC로 옮길 때는 같은 카드에서 그 백업 폴더를 선택한 뒤 **"폴더에서 복원"** 을 누르면 사진까지 되살아난다.
- 앱이 비어 있는데 폴더에는 문제가 남아 있으면 자동 백업이 덮어쓰지 않고 멈춘다("먼저 폴더에서 복원을 하세요" 안내). 유일한 사본이 빈 파일로 바뀌는 일을 막기 위해서다.
- 폴더 안 파일을 손으로 고치지 말 것. 다음 백업 때 앱 상태로 덮어쓴다. 과거 상태가 필요하면 `history/`의 스냅샷을 가져오기에 드롭한다(사진은 `images/`에서 복원).

### 수동 백업

같은 페이지의 "전체 백업 내보내기"로 JSON 하나에 사진까지 저장된다. 자동 백업을 못 쓰는 브라우저이거나, 파일 하나로 들고 다닐 때 쓴다.

### 인쇄 (시험장용)

문제 목록 오른쪽 위 **인쇄** 버튼(단축키 `p`)을 누르면 지금 걸어 둔 필터 그대로 인쇄 화면으로 간다. 세 가지 형식이 있다.

- **오답노트**: 문제 → 정답 → 풀이 → 틀린 이유 순서. 내 답·원본 사진은 체크로 넣고 뺀다.
- **개념 정리**: 풀이 칸의 핵심 개념만 유형별로 모아서. 풀이가 비어 있는 문제는 빠진다.
- **문제만**: 문제에 번호만 붙이고 정답은 맨 뒤 장에 모아 둔다. 직접 풀어 볼 때.

브라우저 인쇄 창에서 대상을 ‘PDF로 저장’으로 고르면 파일로도 남는다. 어두운 테마여도 종이에는 밝은 색으로 나온다.

### Anki로 복습하기

**가져오기 / 내보내기 → Anki 내보내기**에서 빈칸(Cloze) 카드 파일을 만든다. 앞면은 풀이의 핵심 개념에서 정답·태그 용어를 가린 것, 뒷면은 전체 개념과 문제·정답이다.

1. 정답·태그에 나온 용어가 자동으로 빈칸 제안된다. 미리보기에서 **단어를 클릭**하면 빈칸이 되고 다시 클릭하면 풀린다(같은 단어라도 자리마다 따로). 선택은 브라우저에 저장된다. "단어마다 카드 따로"를 켜면 서로 다른 단어 수만큼 카드가 생긴다.
2. **Anki 파일 받기**로 `anki-review-notes-<날짜>.txt`를 받는다.
3. Anki에서 **파일 → 가져오기**로 그 파일을 열고, 노트 유형이 빈칸 채우기(Cloze)인지 확인한 뒤 가져온다. 덱 이름 칸에 적은 덱이 없으면 새로 만들고, 있으면 거기에 추가된다. 표·코드 테두리는 카드 HTML에 스타일을 심어 두었으므로 Anki 쪽 설정이 필요 없다.

같은 문제를 다시 내보내 가져오면 새 노트가 생기지 않고 기존 노트가 갱신된다(문제 id를 guid로 쓴다).

### 단축키

앱 안에서 `?`를 누르면 전체 목록이 뜬다. `n` 새 문제, `/` 검색, `r` 복습, `e` 편집.

## 개발

설계와 결정 사항은 `PLAN.md`, 작업 규칙은 `CLAUDE.md`.

```
npm run typecheck && npm run lint && npm run test
```
